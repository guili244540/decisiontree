Decision Tree

An interactive guide that walks you through decisions, step by step.

This application will present an interactive decision tree: instead of reading a long document, you answer simple questions and follow the path that matches your situation, until you reach the outcome or advice that applies to you.

The goal is to run entirely in your browser, offline, after downloading it, and to be easy to host on any web server such as Apache HTTP Server.

A possible future feature is the ability to load a decision tree from a DMN file, so that trees can be defined in a standard format and shared.

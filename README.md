# decisiontree

An interactive Decision Tree web application.

## Status

This project is **in construction**. The current page only introduces the idea.

## Idea

The goal is a browser-based interactive decision tree: instead of reading a long
document, the user answers simple questions and follows the path that matches
their situation, until reaching the outcome or advice that applies to them.

- Works fully offline: download the files and open `index.html` in any modern
  browser (Chrome, Edge, Firefox, Safari, ...).
- Can also be hosted on any static web server, such as Apache HTTP Server.
- Possible future feature: load a decision tree from a
  [DMN](https://www.omg.org/dmn/) (Decision Model and Notation) file, so trees
  can be defined in a standard format and shared.

## Usage

Open `index.html` in your browser — no build step or dependencies required.
